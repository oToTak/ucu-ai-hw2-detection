# Рішення за замовчуванням

Оркестратор і воркери беруть ці значення, поки автор не змінив рядок. Змінюєш значення: правиш тут, оркестратор підхоплює при наступному запуску воркера. Усі «за замовчуванням» орієнтовні, F і EDA можуть їх уточнити за даними й фіксують у `_protocol.yaml`.

| # | Питання | Значення за замовчуванням | Чому |
|---|---|---|---|
| D1 | Роздільність, крок кадрів, бюджет | довга сторона 960; train кожен 3-й кадр (≈8k); val кожен 5-й для кривої по епохах, повний val в кінці; ≈60–75 хв на ран | Об'єкти 10–30 px, 640 їх втрачає; бюджет має вмістити ≈23 год |
| D2 | Валідація | один hold-out: 7 val-кліпів; k-fold не робимо; у звіті прямо назвати як обмеження | k-fold × 12 ранів не влазить у GPU |
| D3 | Фінальне навчання на train+val | ні для 1x–4x; для 5x лише якщо лишився бюджет і ефект перевірено | Інакше втрачаємо власну валідацію для вибору сабмітів |
| D4 | Локальний torch | не ставимо; перша перевірка коду — Kaggle smoke | Автор просив мінімум тестів |
| D5 | W&B | інтегрований у код з самого початку, ключ як Kaggle Secret `WANDB_API_KEY`; без ключа no-op | B2 вимагає криві з T3–T6, а ззаду їх не відновиш |
| D6 | Які бонуси | порядок B1 → B3 → B2; B2 лише якщо лишається час | B1 CPU і дешевий; B3 дає до +3 |
| D7 | Пороги score у сабміті | `conf` низький (0.001–0.01), до 500 детекцій на кадр | mAP любить повний хвіст; ліміт умови — 500 |
| D8 | Сабміти на Kaggle | кожен серйозний ран пише `submission.csv`; автор вантажить вручну, public score записує в `results/<ран>/public_score.txt` | Звіт вимагає public score для кожного експерименту, де він є |
| D9 | Вибір двох фінальних | за власною валідацією (D2), не за public LB | Прямо вимагає умова |

## Що має перевірити автор на старті (не воркери)

1. Репозиторій `oToTak/ucu-ai-hw2-detection` публічний (Kaggle клонує без токена).
2. На Kaggle: Internet ON, GPU ввімкнений, акаунт підтверджений телефоном, залишок квоти GPU.
3. Вкладка Evaluation змагання: чи метрика справді COCO-подібна mAP (у переданому тексті опису метрики немає). Результат записати сюди: `метрика: …`.
4. Ліміт сабмітів на добу.
5. Для B2: акаунт W&B і Kaggle Secret.
