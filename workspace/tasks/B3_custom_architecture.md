# B3. Бонус: своя архітектура

Змінити модель під цю задачу, наприклад додати голову високої роздільності для дрібних об'єктів. Кожне рішення підтвердити експериментом. Для повного балу потрібен повний лог експериментів і розбір фейлів.

**Готово, коли:** блок `8x` показує порівняння з базовою моделлю.

## Оркестрація

- **Лейн CA · модель opus · хвиля W3 · залежить від T5 (`ul_common`, YOLO) і `handoff/EDA.md`.**
- **Власні файли:** `src/models/custom.py`, `configs/8?_*`.
- **Ідея:** кожне рішення з гіпотезою з EDA і абляцією. Дешеві кандидати в Ultralytics: голова P2 (yaml-архітектура з додатковим рівнем), роздільність входу, заміна loss (наприклад, NWD для дрібних). Обери 2–3 з обґрунтуванням у handoff, запусти порівняння з `30_yolo_base`. Журнал експериментів (що, чому, результат, фейли) веди у `results/80_*/experiments.md`: для повного балу він обов'язковий.
- **Рани:** `80_custom_arch` (+ `81_…`, `82_…`), `89_compare`.
- **Виходи:** `handoff/CA.md`.
- **GPU:** ≈2.5 год. **Smoke:** обов'язковий.
